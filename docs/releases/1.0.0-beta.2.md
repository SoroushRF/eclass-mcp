# v1.0.0-beta.2

Release date: 2026-05-15

## Summary

`v1.0.0-beta.2` is the post-beta hardening release for the eClass MCP engine. It adds Cengage/WebAssign read integration, cross-platform assignment resolution, structured contracts/errors, encrypted local auth sessions, selector drift diagnostics, setup/doctor productization, and release discipline needed before future write tools.

## Highlights

- Added Cengage/WebAssign dashboard-first course discovery, persistent local auth, assignment parsing, bounded all-course aggregation, list/discover tools, and assignment question-detail extraction.
- Added the cross-platform assignment resolver and course-platform mapping index for eClass plus Cengage/WebAssign assignment surfaces.
- Added eClass external-platform discovery from courses, announcements, and item details.
- Added E11 output schemas and E12 structured machine errors.
- Added E13 encrypted auth session storage and local logout wipe.
- Added E14 structured JSON logging with request/tool context and redaction.
- Added E15 selector registry, selector winner logs, `SCRAPE_LAYOUT_CHANGED` drift diagnostics, and optional selector snapshots.
- Added E16 `npm run doctor`.
- Added E17 safe setup dry-run, timestamped backups, backup listing, restore, and atomic Claude config writes.
- Raised branch coverage to 75% with targeted regression tests.

## Upgrade Notes

- Set `ECLASS_MCP_SESSION_SECRET` in `.env` before authenticating.
- Legacy plaintext `.eclass-mcp/session.json` and `.eclass-mcp/cengage-state.json` files are rejected; clear auth sessions with `http://localhost:<AUTH_PORT>/logout` or delete those auth files, then re-authenticate.
- Run `npm run doctor` when diagnosing setup, auth, Playwright, or Claude Desktop config issues.
- Run `npm run setup -- --dry-run` before mutating Claude Desktop config; use `npm run setup -- --list-backups` and `npm run setup -- --restore latest` for rollback.

## Known Limitations

- Write tools are still intentionally gated for future E20/E21 safety work.
- WeBWorK remains pending.
- Secure wipe is best-effort and cannot guarantee physical erasure on SSDs, sync folders, journaling filesystems, or backups.
- Selector debug snapshots are plaintext local debug artifacts and are opt-in only.
