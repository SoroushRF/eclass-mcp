# v1.0.0-beta.2 Commit Audit

This ledger is the forensic source behind `CHANGELOG.md`. It was built from the full reachable history using `git rev-list --reverse --topo-order HEAD`, then checked against `git log` / `git show --find-renames --summary --stat --name-status` evidence. Patch-level inspection was used for commits whose subject or file list did not explain the release impact.

The public changelog is intentionally curated. This ledger is intentionally exhaustive: every reachable commit through the pre-release engineering checkpoint `5c9a6af` is represented. The E18 release-prep commit is represented by the final `E18-SELF` row; a commit cannot embed its own final hash without changing that hash.

Disposition values:

- `Direct`: represented by a specific changelog entry.
- `Folded`: represented inside a broader changelog theme.
- `Historical`: represented in older historical release sections.
- `Omitted`: present in this audit but intentionally not called out in the public changelog.
- `Superseded`: reverted, reapplied, or replaced by a later commit.
